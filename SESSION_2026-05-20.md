# Session Summary — 2026-05-20

## What We Built
Redesigned the expense tracker from 1-user-1-group to **multi-group/wallet** system + added **Loan/Debt Tracker** feature.

## Architecture Decisions (User Confirmed)
| Decision | Choice |
|----------|--------|
| Group switching | JWT embeds active groupId — call `POST /api/me/switch-group` to get new token |
| Leave group | Auto-switch to first remaining group, return new JWT |
| Delete group | Only OWNER; CASCADE deletes via FK |
| Loan scope | Per group (loans.group_id) |
| Interest tracking | Free-text only (future improvement) |
| Installment dates | Auto-calculate from startDate + paymentDay + termMonths, flag overdue |
| Default group on login | Personal wallet (`{username}'s Group` — first created) |
